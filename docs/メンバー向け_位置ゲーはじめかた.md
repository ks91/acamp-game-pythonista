# アカキャン位置ゲー：はじめかた

このフォルダのゲームは、班で一台のiPadを「探検端末」として使う位置情報ゲームです。位置情報は班のゲームのために使い、個人を追跡するものではありません。

## 最初に知っておくこと

- `docs` フォルダは説明書です。Pythonista 3が勝手に実行することはありません。
- 実行するのは **`team_app.py`** です。iPadの `TEAM_ID` に合う班の試作アプリが自動で開きます。
- `config.py` には班ごとの設定とゲームトークンがあります。写真・Discord・GitHubへ貼らないでください。
- Wi-Fi開発iPadは画面確認やコードづくりに使えますが、本番のスポット獲得はCellular iPadだけが行います。

## 今日の起動手順

1. Pythonistaを完全に終了する。
2. Working Copyで `acamp-game-pythonista` を開き、Pullする。
3. Pythonistaを開き直し、Working Copyとつながった同じフォルダを開く。
4. `team_app.py` を実行する。

> ファイルを一つだけコピーしたり、古いPythonistaの画面から実行したりしないでください。`Pythonista終了 → Pull → 再起動` が大事です。

## 画面の使い方

- **現在地を更新**：安全に立ち止まり、屋外または空が見える場所で押します。
- スポット名のボタン：その場所にいると思ったら押します。サーバーが距離・GPS精度・位置情報の新しさを判定します。
- `✓`：その班がすでに獲得したスポットです。

位置情報はスポット獲得の直前に更新してください。古い位置情報、精度の悪い位置情報、範囲外の位置情報では獲得できません。

## 今日のテストスポット

オリンピックセンター内と参宮橋駅付近に、各班用の試作スポットがあります。雨、移動、安全、GPS精度を観察しながら、半径・得点・ヒント・物語を改善してください。

## よくある表示

| 表示 | 意味と次の行動 |
|---|---|
| `位置情報を取得できません` | 屋外や窓際など安全な場所へ移り、位置情報の許可も確認する。移動中に無理に試さない。 |
| `location accuracy is too low` | GPS精度が足りない。少し待って、現在地を更新する。 |
| `location sample is too old` | 位置情報を更新してから時間が経った。もう一度更新する。 |
| `team is outside place radius` | スポット中心から外れている。地図・周囲を観察して安全に移動する。 |
| `device is not allowed to claim` | Wi-Fi開発iPadで本番獲得を試している。Cellular iPadで行う。 |
| 通信できず端末に保存された | 次の位置更新時に自動再送する。`pending-events.json` は編集しない。 |

## 開発・研究の進め方

1. **予想する**：このスポットやルールで、プレイヤーはどんな行動をする？
2. **小さく変える**：名前、得点、半径、ヒント、物語のどれか一つを変える。
3. **試す**：安全に実地テストする。
4. **観察する**：予想どおり？ GPS、雨、移動、他班との関係はどうだった？
5. **改善する**：次に変えることを一つ決める。

班のアイデア、観察、失敗、改善はすべてゲームづくりと研究の大事な材料です。

## 安全

- 道路を渡る・階段を使う・人混みを歩くときは、画面を見ない。
- 雨が強い、風が危険、移動が危ないと感じたら、ゲームより安全を優先する。
- スタッフの停止・移動指示はゲームルールより優先する。
